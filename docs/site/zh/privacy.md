# 数据与网络

本页列出 godot-mcp 保存的一切，以及它发送数据的每一个去处。它在你的机器上运行，只服务启动它的那个客户端，不向任何人报告。

## 它保存什么

一切都在项目自己的 `.godot-mcp/` 目录里：保证一个项目只有一个服务器的锁、事务的持久日志、分析索引、审计日志、编辑器插件读取的会合文件、会话与导出的记录和捕获的输出，以及它们生成的产物——截图、录屏和导出的构建——直到保留期结束。在项目之外，它只写你配置的东西，例如日志文件。在没有服务器运行时删除 `.godot-mcp/`，就能把这些全部移除。

## 它发送什么、发往哪里

| 去向 | 时机 | 内容 |
| --- | --- | --- |
| 启动它的 MCP 客户端（stdio） | 每个请求 | 答复：请求所要的项目数据 |
| 回环 HTTP 客户端 | 只在配置了 HTTP，并且带着密钥或代理凭据时 | 与 stdio 相同的答复 |
| 你的身份提供方 | 只在使用 `proxied_oidc` 时，用来获取它的签名密钥 | 向你配置的签发方请求公开的密钥 |
| 它启动的 Godot 进程 | 每次引擎运行、游戏和编辑器会话 | Godot 读取的项目本身；探针和桥接通过回环通信 |
| 编辑器插件（回环） | 只在插件已连接时 | 编辑器请求及其答复 |

没有遥测，也没有更新检查；服务器从不下载引擎或导出模板。

## 日志

诊断信息写到 stderr，或者写到你配置的滚动日志文件，从不写到 stdout——stdout 只承载 MCP 帧。密钥、令牌和源码文本会在写入之前被遮蔽；答复用项目内的相对路径指代文件，而不是它在你磁盘上的位置。
